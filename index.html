SSH Formateur

  • URL Web : https://172.16.3.10:30443

  • Mot de passe : AdminEfi2026!

efiadmin20 efiadmin20 efiadmin20-ns efiadmin20 Admin de son espace, SSH avec changement de mot de passe obligatoire
💡
Règles de sécurité applicables aux candidats :
  • Connexion SSH : ssh efiadminN@172.16.3.10. À la 1re connexion, la modification du mot de passe est obligatoire.
  • Ressources autorisées : Création de Deployments, Services (ClusterIP, NodePort, LoadBalancer), PVC, Ingress, Pods, Namespaces personnels (ex: lab-efiadmin1).
  • Protection du travail des autres : Toute tentative de modifier/supprimer les ressources d'un collègue ou de la plateforme est bloquée par la règle efi-tenant-protection.
  • Accès Argo CD : Identifiants identiques (efiadminN / efiadminN). Chaque candidat ne voit et ne gère que ses propres applications.

4. Guide Pratique Argo CD (CLI & Web)

Toutes les commandes nécessaires pour manipuler Argo CD en ligne de commande depuis le Master ou le poste de travail :

1. Se connecter à Argo CD via la CLI

Bash — Connexion Admin ou Candidat
# Connexion en tant qu'Administrateur Formateur
argocd login 172.16.3.10:30443 --username admin --password AdminEfi2026! --insecure --grpc-web

# Connexion en tant que Candidat (ex. efiadmin1)
argocd login 172.16.3.10:30443 --username efiadmin1 --password efiadmin1 --insecure --grpc-web

2. Lister les Clusters et les Projets

Bash — Inspection des Clusters et AppProjects
# Lister les clusters enregistrés sous Argo CD
argocd cluster list

# Lister les projets autorisés
argocd proj list

3. Créer une Application Argo CD (CLI)

Exemple complet pour créer une application dans le namespace du candidat sur le cluster local ou externe :

Bash — Création d'Application sur Cluster Local (in-cluster)
argocd app create demo-guestbook \
  --repo https://github.com/argoproj/argocd-example-apps.git \
  --path guestbook \
  --dest-server https://kubernetes.default.svc \
  --dest-namespace efiadmin1-ns \
  --project efiadmin1
Bash — Création d'Application sur Cluster Secondaire (172.16.33.70)
argocd app create demo-cluster33 \
  --repo https://github.com/argoproj/argocd-example-apps.git \
  --path helm-guestbook \
  --dest-server https://172.16.33.70:6443 \
  --dest-namespace efiadmin1-ns \
  --project efiadmin1

4. Vérifier l'état d'une Application

Bash — Consultation du statut et des ressources
# Lister toutes vos applications
argocd app list

# Obtenir le détail complet d'une application (Health, Sync Status, Arbre des ressources)
argocd app get demo-guestbook

5. Synchronisation Manuelle et Automatique (Auto-Sync)

Bash — Lancer la synchronisation ou configurer l'Auto-Sync
# 1. Déclencher une synchronisation manuelle
argocd app sync demo-guestbook

# 2. Activer la synchronisation automatique (Auto-Sync)
argocd app set demo-guestbook --sync-policy automated

# 3. Activer la suppression automatique (Auto-Prune) et l'auto-réparation (Self-Heal)
argocd app set demo-guestbook --auto-prune --self-heal

6. Consulter les Logs et l'Historique de déploiement

Bash — Journaux et révisions
# Afficher les logs d'un conteneur via Argo CD
argocd app logs demo-guestbook

# Afficher l'historique des déploiements (Revisions)
argocd app history demo-guestbook

7. Rollback (Retour arrière) et Suppression

Bash — Annulation et suppression
# Revenir à une version antérieure (ex. ID 1)
argocd app rollback demo-guestbook 1

# Supprimer une application
argocd app delete demo-guestbook
🔄

5. Workflow Exemple pour une Séance de Travail Pratique

  1. Le formateur distribue les identifiants : Candidat N ➔ efiadminN / efiadminN.
  2. Le candidat se connecte en SSH : ssh efiadmin1@172.16.3.10 et change son mot de passe SSH.
  3. Le candidat se connecte sur Argo CD Web : https://172.16.3.10:30443 avec son compte.
  4. Création d'une application Web sur Argo CD :
    • Cliquer sur + NEW APP
    • Application Name : mon-app
    • Project Name : efiadmin1
    • Sync Policy : Automatic (ou Manual)
    • Repository URL : https://github.com/argoproj/argocd-example-apps.git
    • Path : guestbook
    • Cluster URL : https://kubernetes.default.svc (ou https://172.16.33.70:6443)
    • Namespace : efiadmin1-ns
  5. Validation : Cliquer sur CREATE puis SYNC. L'application passe au statut Synced / Healthy.

6. Dépannage & Commandes de Secours (Formateurs)

⚠️
Actions d'urgence réservées au Formateur sur le Master :
Bash — Réinitialisation & Santé
# 1. Vérifier l'état global du cluster K8s
kubectl get nodes -o wide
kubectl get pods -A | grep -v Running

# 2. Réinitialiser le mot de passe SSH d'un candidat (ex. efiadmin3)
passwd efiadmin3 && chage -d 0 efiadmin3

# 3. Réinitialiser la configuration Argo CD Multi-Tenants
/root/k8s-deploy/scripts/k8s-argocd-tenants.sh

# 4. Désactiver temporairement la politique de protection K8s en cas de blocage
kubectl delete validatingadmissionpolicybinding efi-tenant-protection

# 5. Réactiver la politique de protection K8s
kubectl apply -f /root/efi-tenant-protection.yaml
